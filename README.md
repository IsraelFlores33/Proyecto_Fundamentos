# Proyecto_Fundamentos

## ¿Qué es?
Es una aplicación diseñada para simular y gestionar el proceso de consulta de requisitos, postulación y evaluación de solicitudes de becas académicas, financieras y de talento del Tecnológico de Monterrey (ITESM). 
## ¿Para qué sirve?
El sistema permite a los usuarios:
-Consultar el catálogo oficial de becas del Tec.
-Registrar y evaluar solicitudes de aspirantes ingresando su semestre y promedio actual, validando automáticamente si cumplen con los requisitos institucionales.
-Generar porcentajes de beca aleatorios basados en los topes establecidos por cada tipo de apoyo.
-Llevar un historial de solicitudes de la sesión.
## ¿Cómo se usa?
1: Muestra el catálogo con los requisitos de las becas.
2: Ingresa tus datos (nombre, semestre y promedio) para postularte y evaluar tu beca.
3: Muestra el historial de solicitudes con sus folios aleatorios.
4: Cierra el programa.
